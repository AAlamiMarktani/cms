# CRM MERN

CRM simple : React + Express + Node.js + MongoDB Atlas.

## Installation

```bash
cd backend && npm install
cd ../frontend && npm install
```

## Variables d'environnement

- `backend/.env` : voir `backend/.env.example` (MONGODB_URI, FRONTEND_URL, PORT)
- `frontend/.env` : voir `frontend/.env.example` (REACT_APP_API_URL)

## Lancement

```bash
# Terminal 1
cd backend && npm run dev

# Terminal 2
cd frontend && npm start
```

Frontend : http://localhost:3000 — API : http://localhost:4000
